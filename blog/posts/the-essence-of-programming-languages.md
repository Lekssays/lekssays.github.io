In this article, I attempt to explain and summarize the concepts of programming languages, and of programming in general, drawing on my experience as a computer science student, a competitive programmer, and a back-end web developer. I will focus on the theoretical concepts I learned along the way. As I mentioned, I do not call myself an expert in this field, because I believe true expertise in programming languages is very hard to achieve. I am simply trying to simplify some difficult concepts as I understood them from the literature.

## Computational Models of Programming Language Paradigms

Before we discuss why there are so many programming languages, we should classify them. They fall into three main types:

- **Imperative/Procedural:** Languages that follow a set of given steps, or procedures. This category includes C, Python, Ruby, C++, Java, and the majority of languages we use today.
- **Functional:** Languages such as Haskell and Lisp, which have no variables; everything in them is a function. This represents an entirely new way of seeing programming.
- **Declarative/Logical:** Languages such as Prolog, in which we declare a set of rules and a platform on which to apply them. For example, we give the program the rules of Sudoku and a Sudoku board, and it takes care of generating the possible solutions. This type of language is used heavily in Artificial Intelligence.

## Program Organization Models in Programming Languages

This topic differs from computational models, which are concerned only with how to solve problems in a computational manner. Program organization models are more about how your code is organized and how memory is used to represent variables. We can distinguish several types:

- **Abstract Data Types (ADT):** This model treats an abstract data type as a unit in itself, as in the CLU language developed at MIT.
- **Module-based:** This model treats modules as a central part of programs, as in Modula-2. Each program is divided into a set of modules, where a module can be defined as a group of types, variables, procedures, and functions.
- **Object-oriented:** The famous one. Many languages use it, including Java, Python, C++, and Ruby. It treats everything as an object that has attributes and behaviors.
- **Generic:** This model defines generic modules to be instantiated at compile time or runtime in order to create the data structures, functions, and procedures needed. It can intersect with OOP, functional programming, or multiple paradigms.

## Different Purposes of Programming Languages

Learning different programming languages is a good thing, of course, but a programmer should choose languages from different fields. For instance, we cannot learn C to develop a mobile application. We should have a clear idea of why we are programming, or why we want to learn programming, in the first place.

- To develop mobile applications for iOS, we should learn Java and/or Kotlin, as Google mentioned at its last conference.
- To develop web applications, we should learn PHP, JavaScript, Ruby, or Python and their frameworks, such as Laravel, Express (a Node.js framework), Rails, and Django.
- To develop desktop applications, we can learn C#, C++, and Java.

The main idea here is to choose a field and focus on it until we are confident in our understanding of a programming language.
