> “The system as a whole is basically the GNU system, with Linux added. When you’re talking about this combination, please call it “GNU/Linux”.”
>
> Richard Stallman

I am writing this post because almost everywhere I look, people talk about Linux as if it were an operating system. Linux is NOT an operating system. One day, my roommate told me I had said this very sentence in my sleep. And if you really know me, you know this topic is a sensitive one for me.

## Why Terminology Matters

It is genuinely annoying to see tutorials and professors discuss “Linux OS” alongside Windows and macOS. Terminology matters when you are trying to gain knowledge, so I expect some of you to ask: what difference does it make? It makes a big difference. If you made this mistake at one of the prestigious conferences, I believe people would lose faith in you. So be careful about the terminology you use; it can be sensitive in certain contexts.

## Linux Is a Kernel

Linux is a kernel. A kernel is a program that manages the allocation of a machine’s resources for the other programs that run on top of it. It is an integral part of the operating system, but it is useless on its own. On top of that, it has no user-land. Linux is combined with GNU tools to form a GNU/Linux operating system, which is the correct terminology to use.

## What GNU Brings

GNU is a set of rules, ideas, and philosophies that govern free software. At this point, we will not discuss the difference between free software and open source software, because that needs its own post. GNU gave birth to many tools after several attempts to build an independent operating system. The GNU tools are essentially modified, open versions of tools that already existed, brought under the umbrella of open software. GNU/Linux is the operating system that gathers the GNU tools and the Linux kernel together to form a complete whole.

At this point, we should correct a common mistake: the so-called “Linux distributions.” By design, they are GNU/Linux distributions.

## Conclusion

In the end, what I want you to take away is this: when you use the GNU/Linux operating system, or even just refer to it, please do not confuse the world by calling it “Linux.” And I guarantee you that Stallman will be happy to hear it.
